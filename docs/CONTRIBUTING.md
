# Dépannage

## Le plugin ne se charge pas

- Vérifiez que le dossier du plugin est bien placé dans le dossier `Plugins` de LOTRO
- Vérifiez que le dossier n'a pas été extrait dans un sous-dossier supplémentaire
- Vérifiez que le nom du dossier est correct et que le plugin est bien chargé depuis le gestionnaire

## Je ne vois plus l'icône

- Utilisez la commande `/Alt icon` pour la réafficher
- Vérifiez qu'elle n'est pas sortie de l'écran
- Maintenez `ALT` pour la déplacer si nécessaire

## Les personnages sur plusieurs serveurs ont le même nom

- Attention : si plusieurs personnages portent le même nom sur des serveurs différents, certaines fonctions peuvent être moins fiables
- Vérifiez le bon compte et le bon serveur avant de dépanner

## Les données semblent incohérentes

- Vérifiez que le nom du compte est correctement configuré
- Vérifiez le dossier de stockage du personnage
- Supprimez uniquement le fichier de configuration si nécessaire et reconfigurez le plugin

## J'ai un bug après une mise à jour

1. Vérifiez la version actuelle du plugin
2. Vérifiez la [FAQ](../FAQ.md)
3. Ouvrez une issue avec une description claire et, si possible, des captures d'écran
