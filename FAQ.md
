# Contribuer

Merci pour votre intérêt pour ce projet 🙌

## Avant de commencer

- Vérifiez les issues existantes pour éviter de dupliquer un bug ou une fonctionnalité
- Pour une modification importante, ouvrez une issue avant de commencer
- Restez cohérent avec le style et la structure du projet

## Workflow

1. Fork du dépôt
2. Créer une branche : `feature/ma-feature` ou `fix/mon-correctif`
3. Faire des commits clairs et explicites
4. Ouvrir une pull request avec :
   - un contexte clair
   - une description du changement
   - une capture d'écran si l'interface est concernée
   - des instructions pour tester

## Bonnes pratiques

- Garder le style Lua du projet : indentations, noms et structure cohérents
- Limiter le scope des changements à ce qui est nécessaire
- Documenter les changements notable si cela ajoute de la valeur

## Vérification

Avant de soumettre votre PR, vérifiez que :

- le code reste compatible avec le plugin
- les changements ne cassent pas les fonctionnalités existantes
- la documentation est mise à jour si nécessaire

## Questions ?

N'hésitez pas à ouvrir une issue pour discuter d'une idée ou d'un correctif.
