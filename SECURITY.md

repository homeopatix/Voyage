# FAQ

## ❓ Je ne vois plus l'icône

Utilisez la commande :

```text
/Alt icon
```

pour la réafficher.

## ❓ L'icône est hors écran

Maintenez `ALT` puis repositionnez l'icône à l'endroit souhaité.

## ❓ Les données ne semblent pas se synchroniser

Vérifiez que le nom de compte est correctement configuré et que vous êtes bien sur le bon personnage / serveur.

## ❓ Le plugin ne se charge pas

Vérifiez l'emplacement du dossier dans le répertoire `Plugins` de LOTRO et assurez-vous qu'il n'est pas imbriqué dans un sous-dossier supplémentaire.

## ❓ J'ai un bug après mise à jour

- Consultez le [Changelog](CHANGELOG.md)
- Vérifiez les paramètres du plugin
- Ouvrez une issue avec une description précise et, si possible, une capture d'écran
