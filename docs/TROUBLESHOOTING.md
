# Utilisation

## Vue d'ensemble

Voyage permet de gérer rapidement ses téléports de voyage, qu'ils soient liés aux classes, aux réputations, aux races ou aux zones.

## Raccourcis principaux

| Action | Raccourci |
| --- | --- |
| Déplacer l'icône | `ALT` (si l'option est activée) |
| Ouvrir les options | `SHIFT + clic` sur l'icône |
| Afficher la carte de destination | `Clic droit` sur l'icône |

## Fenêtre principale

La fenêtre principale affiche la liste des téléports disponibles et permet de les organiser selon vos besoins.

## Organisation

- Placez les téléports les plus utilisés en haut
- Regroupez par zone ou expansion si votre version le permet
- Gardez une logique de navigation cohérente

## Drag & drop

La fonctionnalité de glisser-déposer permet de réorganiser facilement vos raccourcis selon vos préférences.

## Données & sauvegarde

Les réglages et positions sont stockés par personnage dans le dossier :

```text
Documents\The Lord of the Rings Online\PluginData\<Compte>\<Serveur>\<Personnage>
```

En cas de bug après une mise à jour, il peut être utile de supprimer uniquement le fichier de configuration du plugin, puis de reconfigurer les options.

## Conseils utiles

- Testez les commandes `/Voy toggle` ou `/Alt icon` si vous ne voyez plus l'icône
- Vérifiez les données de compte / serveur / personnage si la synchronisation semble incorrecte
- Consultez la [FAQ](../FAQ.md) et le [dépannage](TROUBLESHOOTING.md)
