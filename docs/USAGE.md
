# Installation

## Prérequis

- LOTRO installé
- Accès au dossier `Plugins` dans le dossier LOTRO de votre système
- Connaissance de votre structure d'installation locale (Windows, Steam, etc.)

## Installation

1. Télécharger le dépôt (`Code` → `Download ZIP`) ou le cloner.
2. Extraire le dossier du plugin.
3. Copier le dossier `Voyage` dans le dossier des plugins LOTRO :

```text
Documents\The Lord of the Rings Online\Plugins\Homeopatix
```

4. Lancer LOTRO.
5. Charger le plugin depuis le gestionnaire de plugins de votre installation.

## Mise à jour

1. Remplacer les fichiers du plugin par la nouvelle version.
2. Conserver vos données si elles sont stockées côté LOTRO.
3. Relancer le jeu et recharger le module si nécessaire.

> Note : les chemins exacts peuvent varier selon la langue, le système d'exploitation ou l'emplacement de votre installation.

## Vérification rapide

Après chargement, vérifiez que :

- l'icône apparaît correctement
- la fenêtre du plugin s'ouvre via le bon accès
- les téléports se chargent sans erreur

## En cas de problème

- Vérifiez l'emplacement du dossier dans le répertoire `Plugins`
- Vérifiez qu'il n'y a pas de doublon ou de dossier imbriqué
- Consultez le guide [Dépannage](TROUBLESHOOTING.md)
