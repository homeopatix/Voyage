# Sécurité

## Signaler une vulnérabilité

Si vous pensez avoir trouvé une faille de sécurité — par exemple une exécution non prévue, une fuite d'informations ou un problème de confiance — ouvrez une issue privée si possible ou contactez directement le mainteneur.

## Versions supportées

- Version courante sur la branche principale (`main`)

## Politique de sécurité

Les correctifs de sécurité sont traités selon leur criticité et leur impact sur le plugin. Merci de ne pas exposer publiquement une vulnérabilité tant qu'un correctif n'a pas été proposé ou publié.
