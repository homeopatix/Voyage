Voyage est un plugin Lua pour The Lord of the Rings Online (LOTRO) permettant d'avoir un accès rapide et organisé à tous vos téléports : voyages de classe, réputations, races et zones.

## ✨ Fonctionnalités

- Accès rapide à tous les téléports
- Voyages de classe (Chasseur, Marin, etc.)
- Téléports de réputation
- Téléports raciaux
- Organisation par cartes et régions
- Drag & Drop des raccourcis
- Verrouillage/déverrouillage des icônes
- Support multi-langues
- Compatible MonsterPlay

## 🚀 Commandes & raccourcis

### Chat commands

| Commande | Description |
| --- | --- |
| `/Voy toggle` | Bascule l'affichage de la fenêtre |
| `/Voy clearteleport` | Efface les raccourcis de téléport |
| `/Voy clearhouse` | Efface les raccourcis de maison |

### Raccourcis

| Action | Raccourci |
| --- | --- |
| Déplacer l'icône | `ALT` (si activé) |
| Ouvrir les options | `SHIFT + clic` sur l'icône |
| Afficher la carte destination | `Clic droit` sur l'icône |

## 🧩 Installation

1. Télécharger le ZIP depuis GitHub ou LOTROInterface.
2. Extraire le dossier.
3. Copier le dossier `Voyage` dans :

```text
Documents\The Lord of the Rings Online\Plugins\Homeopatix
```

4. En jeu, charger le plugin :

```text
/plugins load Voyage
```

Pour plus de détails, voir la documentation d'installation : [docs/INSTALLATION.md](docs/INSTALLATION.md).

## 💾 Données & synchronisation

Les paramètres sont enregistrés automatiquement à chaque connexion / déconnexion.

Les fichiers de données sont stockés dans :

```text
Documents\The Lord of the Rings Online\PluginData\<Compte>\<Serveur>\<Personnage>
```
